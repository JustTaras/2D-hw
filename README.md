# Unity Game Project

## Description
This is a 2D game project developed in Unity using C#.
The project was created for educational purposes to practice
game development, object-oriented programming and Git version control.

## Technologies
- Unity
- C#
- Git
- GitHub

## Quick Start

1. Clone the repository:
   git clone https://github.com/USERNAME/REPOSITORY.git

2. Open Unity Hub.

3. Select "Add project from disk".

4. Choose the cloned project folder.

5. Open the project using the required Unity version.

6. Open the main scene and press Play.

## Usage
The project can be used for studying Unity development,
C# scripting and basic 2D game mechanics.
