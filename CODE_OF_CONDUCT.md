# Code of Conduct

## Our Standards

Participants are expected to:

- Be respectful and polite.
- Communicate professionally.
- Accept constructive criticism.
- Avoid offensive or discriminatory language.
- Respect different opinions and backgrounds.

## Unacceptable Behavior

Harassment, insults, discrimination and personal attacks
are not allowed in this project.

## Enforcement

Project maintainers may remove comments or contributions
that violate this Code of Conduct.
